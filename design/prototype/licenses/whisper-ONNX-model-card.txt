https://huggingface.co/openai/whisper-tiny with ONNX weights to be compatible with Transformers.js.

Note: Having a separate repo for ONNX weights is intended to be a temporary solution until WebML gains more traction. If you would like to make your models web-ready, we recommend converting to ONNX using [🤗 Optimum](https://huggingface.co/docs/optimum/index) and structuring your repo like this one (with ONNX weights located in a subfolder named `onnx`).

Additional optional built-in package: onnx-community/whisper-base, revision
1846881b6b3a3024392c1eea3ad983695bc23925, derived from openai/whisper-base.
Model card: https://huggingface.co/onnx-community/whisper-base/blob/1846881b6b3a3024392c1eea3ad983695bc23925/README.md
Base model card: https://huggingface.co/openai/whisper-base
Weights are fetched directly from the pinned upstream only during explicit
preparation; they are not included in this application's distribution.
