# Reviewed dialogue copies

Saving an existing dialogue original uses the existing New file review. Source shows a one-based Message number and You/Assistant; stored turnIndex is zero-based. Selecting another available message/speaker replaces the draft with its exact original bytes and source references, without inference. Editing the draft shows Edited copy; reselecting a source explicitly restores its original. Merely focusing/blurring an unchanged source number must not discard edits. Ordinary new-file creation has no dialogue source selector.

A review retains an app-owned candidate identity list from its starting snapshot. It cannot select turns arriving later. Save rechecks the selected ID/index/speaker, exact original text and references. Missing/reordered/changed originals refuse; unrelated appended turns do not invalidate an unchanged selection. Manual Save note binds the rendered answer to its stable turn ID and expected text, not a possibly stale display index. Model-proposed current/history captures use the same review after existing exact-original resolution; selecting the wrong speaker remains a model error the user can correct, not a proven semantic diagnosis.

New copied notes optionally retain dialogueCopy schema1 metadata: noteRevision=1, turnId, turnIndex, speaker, quote, refs and edited. quote is the complete selected user/assistant message, including original line endings. edited records whether the reviewed note revision1 differs from it. Assistant copies retain kind=generated and the original answer's note citations; user-message copies use kind=original. Source references retain their existing version/range eligibility checks. Metadata is immutable after creation; subsequent note edits append normal revisions and retain the revision1 origin snapshot. It does not assert that the current note revision still equals the original.

KnowledgeStore.commit reads notes, folders and stored dialogue within one IndexedDB readwrite transaction, then verifies the copy source before putting any new copied note. A source change after UI review is therefore refused atomically, including changes made by another writer. Existing note CAS, duplicate-submit lock and separate post-commit conversation acknowledgement are retained. A new copy cannot be created through this path without a matching stored original. When a capture request is acknowledged, readTurn identifies the explicitly reviewed source; the prior model/read activity is retained separately.

Memory exposes the retained snapshot behind Original message. Full local backups preserve it, and product backup validation rejects malformed origin metadata, a false Original copy/Edited copy assertion against revision1, or inconsistent kind/citation metadata. Markdown export includes the snapshot in frontmatter. Restore treats it as retained historical data: a snapshot is not proof that imported historical dialogue is still present/current, not a signature, not fresh model evidence and not execution/write authority. Existing external backup confirmation/conflict handling remains unchanged. Notes without dialogueCopy are unchanged; no database version change or data deletion is used.
