# Initial local capability preparation

Latest user direction permits alternative local models and asks for a usable initial set, not Bonsai-only work. Settings/Models now offers Initial preparation without changing the accepted navigation. It uses the currently selected supported text model, including a registered custom one; it never forces Bonsai or changes text selection. It proposes Whisper tiny and Tesseract only when those roles are unset. Unsupported existing reader selections and a custom text model with absent files refuse rather than silently substitute/download. Decision and general image/video understanding are not implied by this initial set.

Opening the sheet independently verifies prospective speech/OCR cache assets even if their roles are unset, and uses actual text-worker file presence. Rows show candidate names, verified state or asset size; the total is an upper bound excluding already present roles/app shell. Downloads stays OFF unless the user explicitly changes the shared connection switch. That switch is a real saved connection preference; Cancel/Stop do not undo an explicit separate connection change. Missing assets cannot prepare while OFF; fully prepared local roles can be selected offline using Use models. Existing runtime/license boundaries remain, including unresolved WebML runtime-specific license and no bundled redistribution.

Prepare holds the common synchronous asset gate, processes missing roles sequentially through existing audited adapters, checks Stop across every awaited boundary and stops before later roles. Completed partial asset files may remain and are reverified on retry. Model registration/selection is committed only after all requested roles finish, through one canonical models revision with a reviewed-settings snapshot check and existing transaction/CAS. Failure or Stop before commit does not change model choices. Existing knowledge, revision histories and optional Decision selection remain untouched. Preparation means files available/verified, not model quality or device-execution certification. No generation starts here.
