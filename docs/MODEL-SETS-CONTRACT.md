# Model set contract

Model sets are named presets for the four role selections stored in `Settings > Models`: text generation, decision routing, speech transcription, and image text extraction. They are a convenience for selecting a known combination; they are not executable workflows, downloaded bundles, or device compatibility claims.

The sets are `Bonsai 2 · 2B` and `Bonsai 2 · 4B` (text only), `Compact text` (LFM2.5 230M), `Expanded text` (LFM2.5 350M), `Text + speech` (Bonsai 2 4B, Whisper tiny), `Text + image` (Bonsai 2 4B, Tesseract 7), `Text + media` (Bonsai 2 4B, Whisper tiny, Tesseract 7), and `Local pipeline` (the same roles plus Open d1 Omni 600M for decisions). Each non-empty role must match both its app-owned model catalog and an app-owned adapter with that model ID and capability. Catalog presence and adapter declaration do not prove successful execution or device fit. In particular, catalog-only entries such as D1 3B and Whisper base are excluded from presets while their local runtime adapters are unavailable.

Choosing a set opens a review of each role assignment. Only explicit `Apply set` commits. The pending selection is locked against duplicate apply/dismiss while saving. A stale cross-tab revision refuses without overwriting; settings refresh and the user must choose and review again. A successful application updates the model preference record once, appends its revision using the existing preference writer, and adds selected built-in IDs to their role libraries. It preserves custom model declarations, previously registered library entries, downloaded/prepared assets, appearance, connection settings, memory files, schedules, and activity. It does not download, prepare, load, unload, or execute any model. Network/download settings remain unchanged.

A selected set says nothing about whether the assets are present, the runtime can execute the model on a particular browser/device, or quality/performance is acceptable. Users prepare and verify assets separately. Future custom model registration remains an explicit separate flow; these presets never remove a custom registration.
